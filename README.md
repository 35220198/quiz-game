# ✨ Quiz Arena — Life Approval Edition

An immersive web quiz built with high-contrast, multi-colored typography and smooth interactive states.

---

## 🛠️ Setup Instructions
1. Save `index.html`, `styles.css`, and `scripts.js` into the same folder.
2. To run locally without browser CORS restrictions, open the folder in **VS Code**, launch with **Live Server**, or use any local development server.
